## 入門指南

此網站使用 Hugo 與 [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 主題構建。要在本地進行構建：

1. 安裝 Hugo Extended。
2. 執行 `hugo mod graph` 取得主題 module。
3. 執行 `hugo --minify --cleanDestinationDir` 建置網站。
4. 參考 [GitHub Pages](https://pages.github.com/) 來瞭解如何在 GitHub 上託管網站。
